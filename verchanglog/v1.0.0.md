# v1.0.0

发布日期：2026-08-21

## 版本概述

Send Email Studio 首个稳定版本，提供基于 Excel 数据的批量邮件发送能力，并支持 HTML、文本和 Word 文档模板。

## 新增功能

- 支持 SMTP 登录、STARTTLS、邮件主题和 HTML 正文发送。
- 支持从 Excel 读取收件人、抄送人和附件路径。
- 支持收件人列名按“收件”关键字匹配。
- 支持单元格内使用英文逗号、分号和中文顿号分隔多个邮箱，并自动去重和过滤无效地址。
- 支持按收件人分别发送，或将同一行的多个收件人合并发送。
- 支持按行读取“主题”列覆盖默认主题。
- 支持 HTML、TXT 和 DOCX 模板，并支持 `{列名}` 变量替换。
- 支持 Word 模板中的普通图片以内嵌 CID 图片方式发送。
- 支持 Word/WPS 常见横线对象、段落边框和基本 DrawingML/VML 横线转换。
- 支持 Word 字体、字号、颜色、粗体、斜体、下划线、删除线和段落间距的基础转换。
- 支持 Windows 单文件 EXE 打包。
- 增加 GitHub Actions 自动测试、Windows 构建、SHA256 校验和及 GitHub Release 流程。

## 验证信息

- Python：3.12.10
- 测试：14 项通过
- 打包：PyInstaller 单文件 Windows EXE
- 平台：Windows AMD64

## 已知限制

- Word 复杂浮动布局、文本框、SmartArt、复杂组合对象和精确页面定位暂不保证完全还原为 HTML 邮件布局。
- 邮件客户端对 HTML/CID 图片和 CSS 的支持存在差异，建议 Word/WPS 中将图片设置为“嵌入型/与文字排列”。
- 实际 SMTP 发送仍需根据邮箱服务商配置服务器、端口和授权密码。
