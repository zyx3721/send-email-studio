# v1.0.1

发布日期：2026-10-08

## 版本概述

修复模板变量替换在两类表头与模板写法下报错的问题：Excel 列名现在可以包含英文句点，Word 模板中被拆成多个文本块的变量也能正确识别。

## 修复内容

- 修复列名含英文句点时替换失败：`{列名}` 改为按整段列名精确匹配，不再把句点解析成属性访问。
  - 之前 `{A.1平台CPU}` 会被拆成字段 `A` 加属性 `.1平台CPU`，抛出 `'str' object has no attribute '1平台CPU'`。
- 修复 Word 模板中被拆成多个文本块的变量无法替换：渲染 Word 时把同一段内被切开的 `{...}` 合并，避免 HTML 标签截断占位符。
  - 之前被切开的占位符会抛出 `Invalid format specifier`。
- 兼容保留：未在 Excel 中出现的列名仍按 `{列名}` 原样输出；格式说明符（如 `{数量:.2f}`）与转换符（如 `{姓名!r}`）行为不变。

## 新增脚本

- `scripts/clean.ps1` 与 `scripts/clean.bat`：清理可再生产的缓存与打包中间文件，默认预演，`-Execute` 才真正删除。

## 验证信息

- Python：3.12.10
- 测试：29 项通过（新增 12 项，覆盖含点列名、跨文本块占位符、格式说明符与端到端发送）
- 打包：PyInstaller 单文件 Windows EXE
- 平台：Windows AMD64

## 已知限制

- 若占位符跨越多个段落（`{` 与 `}` 分别写在相邻两段），仍不会被识别，请保持变量写在同一段内。
- 其余限制同 v1.0.0。
